# MicroPad

MicroPad turns any browser into a flexible, customizable control surface. Build multiple layouts, organize controls across resizable grid pages, and drag widgets exactly where you want them—giving you a clean command center tailored to your workflow.

Designed around an extensible plugin system, MicroPad can grow beyond its built-in plugins to support the tools and actions that matter to you. Create your ideal dashboard once, then enjoy fast, synchronized control from a simple modern interface.
